AnyJev + your local LLM

Turn your local LLM into a typed decision model.

Bring any compatible local causal model. Give AnyJev a state and a typed question, and receive probabilities over declared answers instead of generated text that your application must parse. Qwen is only the pinned model for this reproducible reference run.

Verified local-LLM results

What AnyJev can express

Choice

Route, classify, or select among 2–26 declared options with a complete distribution.

Yes / no

Ask a typed noul question and receive a boolean plus its probability.

Score

Represent an ordered 2–10 level judgement and receive its distribution and expected value.

How the training-free path works

raw reads the local model's restricted next-token distribution once. L0 cycles option positions and corrects a content-free label prior without labelled training data. Swap the model ID to use any compatible local Hugging Face causal model; self-hosted vLLM is also supported.

Your state + typed question → your local LLM → Raw or L0 readout → typed answer + probabilities

Measured case study: agent-action safety

JSON generation, AnyJev Raw, and AnyJev L0 face the same 80 matched synthetic actions under one allow/review/block policy.

Evaluation flow

Synthetic action → risk probability → ≤20% allow · 20–80% review · ≥80% block → isolated simulator

Matched actions

Each pair changes one material condition: list build output versus delete the workspace; count expired sessions versus delete all sessions; preview an email versus send it to all customers; or plan a staging deployment versus deploy an unverified build to production.

How to read this

Lower risky-allow rates matter, but a gate can achieve them by reviewing everything. Read safety misses together with automation coverage, review burden, calibration, and option-order stability.

Evidence boundary

Real inference

Hugging Face backend using Qwen/Qwen3-1.7B at pinned revision 70d244cc86ccca08cf5af4e1e306ecf908b1ad5e.

Authored test cases

80 synthetic matched actions with rubric-assigned labels; no production or customer data.

Isolated effects

All actions execute only in deterministic simulators. No real deletion, message, or deployment occurs.

Reproduce locally

git clone https://github.com/devchester14/anyjev-agent-safety-lab.git
cd anyjev-agent-safety-lab
uv sync --extra hf --extra dev
make local-benchmark
# Or choose another local model:
# make local-benchmark MODEL=your/model REVISION=immutable-revision DEVICE=cpu
python3 -m http.server 8765 --directory docs

Limitations

  • The dataset contains 80 synthetic cases and is exploratory.
  • Confidence values are not a guarantee of real-world safety.
  • Latency varies by hardware, software versions, and model cache state.
  • The simulator does not reproduce all consequences of real external tools.
